# Axiom V1.4 – ChatGPT-Installation und Nachweis

Stand: 13.10.2026 · Website 1.4.0 · privates Plugin 2.2.0 (Ziel 2.3.0)

1. In ChatGPT **Plugins** öffnen. Verzeichnis und eigene Plugins sind je nach Konto/Workspace sichtbar.
2. **Bestehendes privates Axiom:** Unter **Persönlich → Von dir erstellt** das vorhandene Plugin auswählen und mit **@Axiom 🐸** verwenden. Nur Eigentümer bzw. berechtigte Editoren können es mit **Plugin Creator** aktualisieren. Keine neue Identität erstellen, wenn ein Update gemeint ist.
3. **Neues eigenes Plugin:** **Plugin Creator** aus dem Plugin-Verzeichnis installieren, mit **@plugin-creator** die gewünschte Konfiguration erstellen. Das Axiom-Web-ZIP ist dafür **kein direkt importierbares Installationspaket**.
4. **Apps separat:** Benötigte GitHub-, Outlook- oder andere Connectoren einzeln installieren/verbinden und Anbieterrechte prüfen. Weder Plugin noch Wizard autorisieren sie von selbst.
5. **Read-only Onboarding:** Axiom nach tatsächlich verfügbaren Fähigkeiten, Agenten, Skills und Connectoren fragen. Einen echten lesenden Test durchführen; keine Mutation zum bloßen Test.
6. **Nachweise:** selected = im Wizard gewählt; installed = Plugin/App in ChatGPT installiert; connected = Provider-Konto verbunden; authorized = konkrete Rechte vorhanden; executable = entsprechendes Tool nutzbar; verified = Live-Ausführung samt überprüftem Ergebnis.

Free, Plus und Pro sind priorisierte Wege, **nicht** Zusicherungen gleicher Plugin-/App-Rechte. Self-Hosted mit lokalem LLM bleibt Planung/Vorschau ohne Installer. Business/Enterprise/Edu sind noch nicht Teil des Wizards.

Dokumentation: https://help.openai.com/en/articles/20001256-plugins-in-chatgpt

Grenze: Dieses öffentliche statische Portal kann weder ein fremdes Konto prüfen noch ein privates Plugin installieren oder Autorisierung vergeben. Persönliche Plugins sind nicht automatisch öffentlich teilbar.
