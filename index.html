So funktioniert deine Auswahl

Anleitung · kein Login

Für den einfachen Einstieg: ChatGPT übernimmt das KI-Gespräch. Axiom stellt die Orchestrator- und Skill-Logik bereit und nutzt nur die Apps/Plugins, die dein Konto tatsächlich verwenden darf. Hier wird kein eigener Server betrieben.

Du in ChatGPT→Axiom 🐸→Freigegebene Apps/Plugins

Das brauchst du

  • Ein ChatGPT-Konto und Internetzugang.
  • Das Axiom-Plugin, sobald es öffentlich verfügbar ist; bis dahin eine vorhandene private Installation.
  • Nur bei Bedarf zusätzliche Apps/Plugins für GitHub, E-Mail, Kalender usw.
  • Keinen Raspberry Pi, keinen MCP-Server und kein lokales Sprachmodell.

So richtest du es ein

  1. In ChatGPT prüfen, welche Apps/Plugins verfügbar sind.
  2. Axiom installieren oder im privaten Testzugang öffnen, sofern freigegeben.
  3. Gewünschte Integrationen einzeln verbinden und Berechtigungen prüfen.
  4. Eine ungefährliche Leseabfrage ausprobieren.
Beispiel: „Axiom, fasse meine nächsten Termine zusammen.“ Das funktioniert nur, wenn ein entsprechender Kalenderzugriff tatsächlich verbunden und autorisiert ist.

Für Nutzer mit eigener Hardware: ChatGPT bleibt die KI. Über einen geeigneten Connector, beispielsweise Remote Desktop Commander, kann Axiom auf ausdrücklich freigegebene Funktionen deines eigenen Rechners oder Servers zugreifen.

Du in ChatGPT→Axiom + Connector→Dein Pi / NAS / PC

Das brauchst du

  • ChatGPT mit einem passenden, verfügbaren und autorisierten Connector.
  • Eigene Hardware: z. B. Raspberry Pi, Mini-PC, NAS, Linux-Server oder Desktop-PC.
  • Eine sichere Verbindung zum Gerät, passende Zugriffsrechte und möglichst ein Backup.
  • Das Gerät muss laufen, wenn du darauf zugreifen möchtest. Dauerbetrieb ist nur für dauerhafte Verfügbarkeit nötig.
  • Kein lokales LLM erforderlich.

So funktioniert die Einrichtung

  1. Eigenes Gerät einrichten und die gewünschten Daten oder Dienste vorbereiten.
  2. Einen unterstützten Remote-Connector mit minimalen Rechten einrichten.
  3. In ChatGPT nur den tatsächlich benötigten Connector freigeben.
  4. Mit einer lesenden Status- oder Dateiabfrage beginnen; Schreibrechte später separat prüfen.
Beispiel: „Axiom, zeige mir den Backup-Status meines Raspberry Pi.“ Hybrid heißt nicht, dass ChatGPT plötzlich direkt auf das Heimnetz zugreifen kann – das erledigt nur eine dafür eingerichtete Verbindung.

Für Fortgeschrittene: MCP (Model Context Protocol) ist ein Standard, über den ein MCP-Server Werkzeuge bereitstellt, die ein MCP-fähiger KI-Client nutzen kann. Der MCP-Server ist nicht selbst das Sprachmodell.

ChatGPT mit Dev Mode oder lokaler KI-Client→MCP-Verbindung→Eigener MCP-Server

Das brauchst du

  • Ein Gerät für den MCP-Server (Pi, Mini-PC, NAS, PC oder geeigneter Host).
  • Einen MCP-fähigen Client als Gegenstelle.
  • Weg A: ChatGPT Pro mit Entwicklermodus (MCP lesen/abrufen) oder Business / Enterprise / Edu mit passenden Workspace-Freigaben (erweiterte MCP-Aktionen in Beta).
  • Weg B: Ein eigenes lokales Sprachmodell mit MCP-fähiger Client-Software – dafür wird kein ChatGPT-Abo benötigt.
  • Für ChatGPT einen von ChatGPT erreichbaren Remote-MCP-Endpunkt; bei lokalem Server z. B. einen Secure MCP Tunnel.

So richtest du MCP ein

  1. KI-Client auswählen: ChatGPT mit unterstütztem Plan oder lokale KI mit MCP-Client.
  2. MCP-Server auf deiner Hardware installieren, die benötigten Tools definieren und absichern.
  3. Nur die benötigten Verbindungen und Berechtigungen einrichten; bei ChatGPT eine geeignete Remote-Verbindung nutzen.
  4. Im Client die MCP-Verbindung autorisieren und zunächst eine lesende Funktion testen.
Wichtig: Bei ChatGPT Pro sind eigene MCP-Verbindungen im Entwicklermodus derzeit auf Lesen/Abrufen beschränkt. Erweiterte Schreibaktionen werden für Business, Enterprise und Edu in Beta bereitgestellt und benötigen passende Berechtigungen. Free und Plus bieten nicht automatisch einen frei konfigurierbaren eigenen MCP-Server in ChatGPT.

Die lokale KI ist eine Alternative zu ChatGPT, keine zusätzliche Pflicht. Andere MCP-fähige Clients sind ebenfalls möglich. Ein lokaler Server ist für ChatGPT nicht unmittelbar erreichbar; ein gewöhnlicher privater VPN-Zugang allein verbindet die ChatGPT-Cloud nicht automatisch mit ihm.

Offizielle Hinweise: Developer Mode & MCP in ChatGPT ↗

Begriffe kurz erklärt: Plugin/App = eine Integration in ChatGPT · Hybrid = ChatGPT und eigene Hardware über einen Connector · MCP = standardisierte Schnittstelle zwischen KI-Client und Werkzeugserver.
